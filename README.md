# One-Liner Laugh Lab

Entry for [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) on make.fun.

One short funny line answering the prompt — the excuse a robot vacuum
gives after eating a sock. Instead of the usual "it was an accident",
the vacuum claims it was running an investigation into why the sock
kept trying to escape under the bed, and closes with the deadpan verdict
that the sock tasted guilty. The joke comes from the fit: a vacuum
treating a sock like a fugitive.

`main.py` writes the line to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
